🔐 SECURITY FEATURES
═══════════════════════════════════════════════════════════════════════════════
✅ Hashed passwords          PBKDF2-SHA256
✅ CSRF tokens               Every POST request
✅ Session timeout           10 min auto-expire + countdown
✅ Rate limiting             5 fails = 15 min lockout
✅ Security headers          X-Frame, CSP, XSS Protection
✅ Audit log                 Every action recorded
✅ Input validation          HTML escaped + length limited
✅ Path traversal prevention os.path.basename() on files
✅ HttpOnly cookies          JavaScript can't access
✅ Session fixation prevent  Regenerated on login
✅ Role enforcement          Server-side checks

⏱️ SESSION MANAGEMENT
═══════════════════════════════════════════════════════════════════════════════
• Auto-expires after 10 minutes of inactivity
• Countdown timer shown in top bar
• Click ↻ button to manually reset timer
• Refresh page (F5) doesn't reset timer
• Logout clears session immediately


🔄 HOW TWO LAPTOPS SYNC
═══════════════════════════════════════════════════════════════════════════════
Admin creates bill
    ↓
Flask saves to store_bills.xlsx
    ↓
WebSocket sends notification to all connected browsers (optional)
    ↓
Staff's browser pops toast notification
    ↓
Bill History auto-refreshes
    ↓
Both see the same bill instantly ✅
